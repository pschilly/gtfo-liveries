# Global Task Force Overlord Official Livery Pack

The follow repository was created for the purpose of providing a method for members of Global Task Force Overlord (GTFO) to both collaborate on the creation of, as well as, distribution of custom liveries for usage within our Digital Combat Simulator (DCS) community.

## Installation

### Option 1: Automated Installer (Recommended)

The automated installer is a lightweight (~1 KB) script that automatically detects your DCS installation, downloads the latest liveries directly into your DCS Saved Games folder, verifies file integrity, and skips files you already have.

1. Download **[`install.bat`](https://raw.githubusercontent.com/pschilly/gtfo-liveries/main/install.bat)** (or grab it from the [Latest Release](https://github.com/pschilly/gtfo-liveries/releases/latest)).
2. Save and double-click **`install.bat`** on your PC.
3. Follow the on-screen prompts.

> **Tip:** Keep `install.bat` on your desktop or in your DCS folder and double-click it anytime you want to check for and install new GTFO livery updates!

---

### Option 2: Manual Installation

If you prefer to manually place the files:

1. Download and extract the latest zip from the [Releases Page](https://github.com/pschilly/gtfo-liveries/releases).
2. Copy the contents of the `Liveries/` folder from the download into your DCS Saved Games folder:
   - **Standard DCS:** `C:\Users\<YourUsername>\Saved Games\DCS\Liveries`
   - **DCS Open Beta:** `C:\Users\<YourUsername>\Saved Games\DCS.openbeta\Liveries`
3. Overwrite any existing files when prompted.
4. Restart DCS World to see the new liveries.
